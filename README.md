# Computational Learning Theory

Academic repository containing rigorous mathematical proofs, theoretical analytical frameworks, and problem sets for the **Computational Learning Theory** course at the National and Kapodistrian University of Athens (NKUA).

## Course Documentation
* `course_assignments_specifications.pdf`: The official academic syllabus containing the formal theoretical problem statements and core question definitions for all assignments.

## Repository Structure
The repository is organized into dedicated topic directories, each containing the analytical problem statement, the required asset fragments, the LaTeX source code, and the compiled publication-ready PDF document:

* `assignment1-rank_estimation/` - Rank estimation bounds & Dvoretzky-Kiefer-Wolfowitz (DKW) inequality applications.
* `assignment2-query_counting/` - Population estimation and uniform sampling bounds via stochastic binary query models.
* `assignment3-kolmogorov_distance/` - Distribution agnostic learning metrics under Kolmogorov and Total Variation metrics.
* `assignment4-learning_rectangles/` - Sample complexity bounds and exact VC Dimension derivation for axis-aligned hyperrectangles.
* `assignment5-two_source_learning/` - Information-theoretic reduction proving learnability equivalence under label-conditional oracles.
* `assignment6-truncated_statistics_sgd/` - Truncated Gaussian parameter estimation using Projected Stochastic Gradient Descent over NLL loss.
* `assignment7-perceptron_lower_bound/` - Worst-case adversarial boundary configurations evaluating lower bounds for the Perceptron algorithm.

## Core Theoretical Focus
* **PAC Learning Framework:** Sample complexity analysis, generalization thresholds, uniform convergence, and agnostic learning tracks.
* **Vapnik-Chervonenkis (VC) Dimension:** Structural risk minimization, shattering thresholds, and combinatorial upper/lower bounds.
* **Stochastic Optimization:** Empirical Risk Minimization (ERM), Novikoff's limits, and optimization geometry under geometric constraints.
